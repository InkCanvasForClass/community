# 手掌擦：TouchSuite 行为对照

参考固定为 [TouchSuite.App 719f06e0d173e26b285de0693236b6561476f81f](https://github.com/PrefacedCorg/TouchSuite/tree/719f06e0d173e26b285de0693236b6561476f81f/src/TouchSuite.App)，主要对应 `Eraser/EraserEngine.cs`、`Eraser/ContactTypes.cs`、`HidReader.cs` 和预览页的分组绘制逻辑。生产代码为按行为重新实现的独立内核；对照测试从外部检出目录读取固定提交，参考源码只落在被忽略的 `artifacts/tests`，不随应用分发。

## 识别与尺寸

- 所有测量统一为物理像素；原有 v1 校准记录仍保存 DIP，在边界按当前且匹配的校准环境转换。旧数据不丢弃。
- 软件接触尺寸乘 DPI；HID 尺寸计数按逻辑最大值映射到屏幕分辨率。等比例换算使用两轴倍率的几何平均，保持面积不变。
- 每个触点独立保存 5 帧尺寸中值、原始位置、面积峰值及锁定状态。同一重复帧不占用窗口，退化接触框不使来源失效。
- 面积阈值默认 `(手指接触面积 + 手掌接触面积) / 2`，手动值单位为物理像素²。关闭面积判定后，仅多点判定可以触发擦除；两项都关闭时全为书写。这以参考项目 `IsWriting` 的实际实现为准。
- `K = 描摹外接矩形面积 / 标定手掌接触面积`；缺少分母才退回各触点峰值面积之和。倍率为面积倍率，不能直接作为边长倍率。
- 随尺寸、固定大小、下限、上限、接触/描摹/自定义比例均走相同面积计算。椭圆外接框按 `πWH/4` 修正。
- 默认不锁定。锁定仅在随尺寸或压力至少启用一项时生效，保持本次判定并取本次最大擦除面积。尺寸平滑要求两轴均落在 1.5% 死区内；压力为 0.20 EMA、0.004 死区，300ms 过期。
- 多点按按下时间差分组，锚点等待默认 200ms 后，使用组内各触点历史中心的跨度与描摹宽高比较。已定夺触点可被新锚点纳入，判定方式与参考实现一致。多点手掌合成重心处的一个标定面积擦除区。

## 输入与生命周期

`PalmEraserEngine` 不访问控件、磁盘或线程调度器。WPF、WinRT 和校准预览均使用它；只有适配层管理湿墨取消、捕获、几何擦除和撤销。

来源观察期和新鲜窗口都是 300ms。自动模式优先 HID，稳定后持续锁定；空帧和抬手不解锁，设置变更或显式重置才解除。原始 HID 使用实际 `WM_INPUT`，不把 WinRT 指针视作 HID。每个子报文及 LinkCollection 分别解码，使用设备容器 ID 共享同屏集合压力，压力缓存 250ms。无法取得容器 ID 时保留完整设备路径，避免把同型号的两块屏错误合并。原始输入注册由全进程单例持有，校准页通过订阅共用，不覆盖主窗口注册。

与预览程序宿主相比，白板适配层增加以下生命周期保护：

- 工具栏及外部窗口的触点不参与擦除；Raw HID 在按下时进行一次命中分类，移动不反复遍历控件树。
- 显式抬手、取消或捕获丢失及时清除触点，不必等待 300ms；不会把取消坐标补画成擦除线。
- 分组成员变化时重建几何命中器，切断重心跳变产生的连线，同时保留当前撤销事务。
- 两个方向的跨线程队列均有界，溢出先结束旧交互；退役的 WinRT 宿主不会再接收新报告。
- 升级为手掌时仅取消正在采集的湿墨，不删除此前的干墨。被抑制的触点到抬手前不重新提交尾部笔画。

## 设置与兼容

校准页可配置来源、HID 设备键、尺寸换算、跟随/锁定/平滑、大小限制、压力、面积和比例；多点数量/时间窗/容差同样持久化。新字段在旧配置中缺失时使用参考默认值，损坏的数值和枚举在反序列化时幂等归一化。保存失败会回滚校准、笔尖及手掌选项。

校准的自动模式先观察稳定来源后开始采样，避免首帧的软件/HID竞争污染面积数据；需要持续按压至少 300ms。HID 校准绑定当时的设备键，双屏复制时可明确区分设备。若切换设备或分辨率/DPI，应重新校准。

没有有效校准时，适配层保留原版本阈值和大小的兼容初值；校准后完全使用上述面积和中值规则，旧敏感度不再修改标定阈值。鼠标的 1×1 模拟仅用于预览，不可保存成真实硬件校准。实际设备完全不提供接触面积时，不会凭空制造面积数据。

## 验证

```powershell
./build/TestTouchSuiteParity.ps1 -TouchSuitePath <固定提交的外部检出目录>
dotnet run --project build/ReliabilityTests/ReliabilityTests.csproj -c Release
dotnet build "Ink Canvas.sln" -c Debug -p:Platform=x64
```

对照程序只将参考内核的时钟替换为确定性时钟，保持识别和计算原样；576 组场景覆盖尺寸、压力、锁定、来源、设备隔离、面积限制、比例、形状及过期状态，比较超过 126 万次。可靠性用例额外覆盖 DIP 迁移、100/150/200% 缩放、分组重心、复用 ID、取消及队列上限。

仍需真实双触摸屏的复制显示、设备热插拔、各类 HID 描述符及不同缩放组合验收。自动测试不能证明驱动提供了可靠的面积/压力数据。

Windows 接口约束参见 [Raw Input](https://learn.microsoft.com/en-us/windows/win32/inputdev/about-raw-input)、[HIDP_CAPS](https://learn.microsoft.com/en-us/windows-hardware/drivers/ddi/hidpi/ns-hidpi-_hidp_caps) 和 [CoreInkIndependentInputSource](https://learn.microsoft.com/en-us/uwp/api/windows.ui.input.inking.core.coreinkindependentinputsource)。
